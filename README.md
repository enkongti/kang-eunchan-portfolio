# Personal Portfolio

개인 포트폴리오 웹사이트입니다.

## 프로젝트 구조

    portfolio/
    │
    ├── index.html
    ├── style.css
    ├── script.js
    ├── images/
    │   ├── profile.jpg
    │   ├── project1.png
    │   ├── project2.png
    │   └── project3.png
    └── README.md

## 주요 기능

-   반응형 웹 디자인
-   다크 테마 UI
-   타이핑 애니메이션
-   프로젝트 카드
-   Skills 섹션
-   Contact 폼
-   부드러운 스크롤
-   상단 이동 버튼

## 사용 기술

-   HTML5
-   CSS3
-   JavaScript
-   Font Awesome
-   Google Fonts (Poppins)

## 실행 방법

1.  프로젝트를 다운로드합니다.
2.  `images` 폴더에 `profile.jpg`, `project1.png`, `project2.png`,
    `project3.png`를 추가합니다.
3.  `index.html`을 브라우저에서 열면 바로 실행됩니다.

## 배포

GitHub Pages 또는 Netlify를 이용하면 무료로 배포할 수 있습니다.
